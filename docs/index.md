# IronBuddy 铁伴儿

本地运行的 iOS 健身训练 App，基于 MediaPipe BlazePose 实时识别动作、自动计数并给出纠错建议。

## 文档

- [隐私政策 Privacy Policy](./privacy.html)
- [铁伴儿 HarmonyOS 版隐私政策](./ironbuddy-hos-privacy.html)
- [GitHub 仓库](https://github.com/Mibslee/IronBuddy)

## 核心特性

- 完全本地运行，零数据上传
- 四大动作：俯卧撑 / 深蹲 / 硬拉 / 卧推
- 动作回放 + 慢动作调整建议（V2.0）
- 自适应强度分析（V2.0）
- HealthKit 同步
